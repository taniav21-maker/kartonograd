# Картоноград — Лендинг детского картонного конструктора

Адаптивный лендинг, созданный с помощью AI-агента OpenCode по реальному техническому заданию. Альтернатива no-code конструкторам с фокусом на производительность и полный контроль над кодом.

## 📋 Техническое задание

Проект реализован по полному ТЗ с 10 блоками:

1. **Полоса "Подарок к Новому году"** — временный промо-баннер с localStorage
2. **Hero** — главный экран с призывом к действию
3. **Catalog** — каталог из 3 товаров с рабочей корзиной
4. **What's in the Box** — состав коробки с детализацией
5. **Collection** — коллекция фигурок с фильтрацией по категориям
6. **FAQ** — вопросы-ответы с аккордеоном
7. **Final** — финальный призыв к действию  
8. **Banners** — два дополнительных баннера
9. **Sticky Button** — закрепленная кнопка для мобильных
10. **Features** — блок преимуществ продукта

## 🛠 Технологический стек

- **Astro** — статический генератор сайтов
- **Tailwind CSS** — утилитарный CSS фреймворк
- **Vanilla JavaScript** — вся логика без фреймворков
- **GitHub Actions** — CI/CD для автоматического деплоя
- **LocalStorage** — сохранение состояния корзины и промо

## 🚀 Ключевые особенности

### 🛒 Рабочая корзина
- Добавление/удаление товаров
- Изменение количества
- Применение промокодов (KARTON10 = 10% скидка)
- Сохранение в localStorage
- Расчет итоговой суммы

### 🎨 Интерактивные элементы
- **FAQ-аккордеон** с плавной анимацией
- **Фильтрация коллекции** фигурок (Звери, Техника, Космос, Новинка)
- **Умная закрепленная кнопка** для мобильных (появляется при прокрутке)
- **Модальные окна** товара и корзины
- **Promo-баннер** с сохранением состояния закрытия

### 📱 Адаптивный дизайн
- **Мобильные** (390px): одна колонка, скрытое меню
- **Планшеты** (768px): две колонки в каталоге
- **Десктоп** (1440px): три колонки, полная навигация

### ⚡ Производительность
- **100/100 Performance по Lighthouse**
- Статическая генерация Astro
- Оптимизированные изображения
- Минимальный JS бандл
- Critical CSS inlining

## 📦 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/taniav21-maker/kartonograd.git
cd kartonograd

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev

# Собрать для продакшена
npm run build

# Предпросмотр собранного сайта
npm run preview
```
