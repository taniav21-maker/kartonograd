# Картоноград — картонный конструктор для детей

Лендинг для детского картонного конструктора "Картоноград" с полным функционалом магазина на чистом JavaScript.

## 🚀 Функционал

### Основные блоки
1. **Hero** — главный экран с призывом к действию
2. **Catalog** — каталог товаров с корзиной (3 набора)
3. **WhatsInTheBox** — состав коробки
4. **Collection** — коллекция фигурок с фильтрацией
5. **FAQ** — вопросы-ответы с аккордеоном
6. **Final** — финальный призыв к действию
7. **Banners** — два дополнительных баннера
8. **PromoBanner** — временная полоса с промо
9. **StickyButton** — закрепленная кнопка для мобильных

### Технологии
- **Astro** — статический генератор сайтов
- **Tailwind CSS** — утилитарные стили
- **Vanilla JavaScript** — вся логика без фреймворков
- **LocalStorage** — сохранение корзины и состояний

### Особенности
- Полностью адаптивный дизайн (390px, 768px, 1440px)
- Модальные окна товара и корзины
- Фильтрация фигурок по категориям
- FAQ-аккордеон с плавной анимацией
- Липкая кнопка для мобильных с IntersectionObserver
- Промо-баннер с сохранением состояния в localStorage
- SEO-оптимизация: мета-теги, alt для изображений, один H1

## 🛠 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/username/kartonograd.git
cd kartonograd

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev

# Собрать для продакшена
npm run build

# Предпросмотр собранного сайта
npm run preview
```

## 🌐 Деплой на GitHub Pages

### Автоматический деплой (рекомендуется)
1. Создайте репозиторий на GitHub с именем `kartonograd`
2. Загрузите код в репозиторий
3. Включите GitHub Pages в настройках репозитория
4. GitHub Actions автоматически развернет сайт при каждом push в main

### Ручной деплой
```bash
# Собрать проект
npm run build

# Файлы для загрузки находятся в папке dist/
```

## ⚙️ Конфигурация

### Изменение base URL
В `astro.config.mjs` измените значение `base` в соответствии с именем репозитория:

```javascript
const base = '/kartonograd/'; // Замените на имя вашего репозитория
```

Варианты:
- `base: '/'` — если репозиторий называется `username.github.io`
- `base: '/kartonograd/'` — если репозиторий называется `kartonograd`
- `base: '/my-project/'` — если репозиторий называется `my-project`
